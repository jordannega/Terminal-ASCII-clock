# daybar 🕐

A tiny terminal clock that doesn't just tell you the time — it shows you
how much of your day is already gone.
⏰ 14:37:02 Friday, September 11, 2026

[████████████████████░░░░░░░░░░░░░░░░░░░░] 60.93%

52,622 / 86,400 seconds today

text

## Why?

Because watching a progress bar creep toward 100% is weirdly motivating.
One file. No dependencies. Pure Python stdlib.

## Run

bash
python clock.py
Press Ctrl+C to quit.

Features
Live clock, updates every second

Visual progress bar for the day

Seconds elapsed counter

Works on Linux, macOS, and Windows
